📚 Grade 12 Study Web App

A creative and interactive study platform designed to empower Grade 12 learners with the tools they need to study smarter, stay motivated, and bag distinctions. 
Built with love and ambition to make academic excellence fun, trackable, and community-driven.

💻 Created by Nontando Myoli

🚀 Features
✅ Timetable Generator
Create your own weekly study schedule by selecting Grade 12 subjects and time slots.

🧠 Quiz Mode
Practice MCQ-style quizzes to prepare for tests and final exams. More subjects will be added over time!

📄 Past Papers Section
Quick access to previous exam papers for real-time practice.

🎯 Bag Distinctions Page
Features:

🎓 Motivational study tips

✅ Revision task checklist

📈 Progress bar tracker

🎯 Subject goals section

🤖 Interactive Chatbot
A helpful, nameless JavaScript-powered chatbot that assists with Life Sciences queries and is always ready to chat while you revise!

💬 Student Community Groups (Upcoming)
Join virtual discussion spaces for each subject to ask questions, collaborate, and study together.

🛠️ Tech Stack
HTML5

CSS3

JavaScript (Vanilla)
